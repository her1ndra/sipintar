# Migrasi lama (arsip)

File di folder ini adalah migrasi dan dump skema lama (sampai 22 Sep 2026).
Semuanya **sudah tergabung** di `database/si_pintar.sql` (dump terbaru).
Jangan dijalankan ulang pada database yang dibuat dari dump terbaru.

Migrasi baru ada di `database/migrations/` dan dijalankan dengan `php database/migrate.php`.
